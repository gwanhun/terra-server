대기조회 상태
⚠️ 해제·삭제·명령은 프로덕션 API(api.terra-server.uk)로 호출해야 mosquitto 계정 정리와 실제 전달이 된다. 신규 등록(pair)·가입은 앱에서 한다. 이 페이지는 서버 .env ADMIN_EMAILS(또는 ADMIN_USER_IDS) 에 든 계정으로 로그인해야 목록이 뜬다(아니면 403 + 내 이메일·uid 안내).
⚙️ 필터 · API 대상
테스터 이름은 shared.js BETA_NAMES_DEFAULT(또는 localStorage terra-beta-names {이메일: 이름}) 기준으로 카드에 붙는다. 베타/그 외 구분은 카드의 [베타] 토글 → 서버 PATCH /admin/accounts/{id} (관리자 공통).

권장: 1대만 골라 prepare → apply → verified 확인(canary) 뒤 나머지. 서버는 기기당 진행 중 작업 1개만 허용(409 active job exists), 같은 버전이면 409 already on this version. ready 가 되면 apply 전까지 지금 버전으로 계속 동작. apply 뒤 5분 안에 새 펌웨어가 MQTT 로 못 붙으면 자동 롤백.
