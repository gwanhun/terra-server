🎯 목표 환경 (device_settings)

목표 온/습도 조회·수정. 서버가 범위(-20~60℃, 0~100%)·min≤max 검증 후 저장 (REST GET/PATCH /devices/{id}/settings).

🖥 LCD 커스텀 텍스트 (Stage I)

디바이스 LCD 상단에 텍스트 표시(한글 가능). 서버가 비트맵 렌더 → NVS 저장(재부팅 유지). 권장: 한글 ~8자 / 영문 ~12자 (넘으면 자동 축소).
