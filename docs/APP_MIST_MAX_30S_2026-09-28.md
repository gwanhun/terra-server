# 앱 전달 — 분무 상한 30초 펌웨어: 10초 분무가 분할 없이 한 번에 나갑니다

> **대상**: 앱 개발 담당
> **작성**: terra-server 백엔드 담당, 2026-09-28
> **성격**: 9/23 회신([BACKEND_HANDOFF_REPLY_MIST_DURATION_2026-09-23.md](BACKEND_HANDOFF_REPLY_MIST_DURATION_2026-09-23.md))에서 "보류"했던 **펌웨어 상한 상향**을 이번 리플래시에 포함했습니다. 서버·앱 계약은 그대로이고, **앱에서 할 일은 없습니다.** 관찰되는 동작 차이만 알려드립니다.
> **관련 커밋**: 펌웨어 nano `a09772f` / supermini `7ed013d`. 서버 코드 변경 없음(문서만 `291930c`).

---

## 0. 요약

| # | 항목 | 앱에서 할 일 | 권장도 |
|:---:|---|---|:---:|
| ① | 신 펌웨어 기기는 10초 분무가 **1회 명령·10초 연속 분사** | 없음. 기존 5초·10초 칩 그대로 | — |
| ② | `commands` 에 `source='timer'` 후속 행이 **안 생김** (신 펌웨어 기기) | 이력 화면에서 후속 행 유무로 분기하는 코드가 있으면 확인 | 확인 |
| ③ | 버튼 잠금 시간 | **총 분사 시간 + 3초** 규칙 그대로 (10초 → 13초). 바꿀 필요 없음 | — |
| ④ | `devices.capabilities.mist_max_ms` 가 `30000` 으로 보임 | 볼 필요 없음(9/23 결정 그대로) | — |

## 1. 무엇이 바뀌었나

| | 구 펌웨어 (~9/28) | 신 펌웨어 (9/28+) |
|---|---|---|
| 펌웨어 분무 1회 상한 | 5초 (`MIST_MAX_MS 5000`) | **30초** |
| `capabilities.mist_max_ms` 보고 | 없음 → 서버가 5000 으로 간주 | **30000** — 페어링 body 와 3초 telemetry 양쪽에 실림. 재페어링 없이 첫 telemetry 에서 서버 DB 갱신 |
| 앱이 10초 분무 요청 시 | 서버가 5초 + 5초로 분할 (총 ~12초, 중간 2초 쉼) | **한 번에 10초** 연속 분사 |
| `commands` 행 | 원 명령 1 + 후속 `source='timer'` 1 | **원 명령 1 만** |
| 5초 분무 | 한 번에 | 한 번에 (변화 없음) |

- 서버 허용값(`duration_ms` 1000/2000/3000/5000/7000/10000)은 **그대로**입니다. 30초는 서버 이상값·침수 방지용 펌웨어 최후 방어선이지, 앱이 30초를 보낼 수 있다는 뜻이 아닙니다(보내면 400).
- 분할 로직은 서버에 그대로 남아 있습니다. 구 펌웨어 기기는 계속 분할되고, 기기별로 자동 판단됩니다. 리플래시 순서와 무관하게 앱 동작은 같습니다.

---

## 2. 앱에서 확인할 것 (선택)

1. 명령 이력이 `source='timer'` 후속 행의 존재를 전제로 하는 표시(예: "2회 분사")가 있다면, 신 펌웨어 기기에서는 1행만 오는 것이 정상입니다.
2. 버튼 잠금은 9/23 규칙(총 분사 시간 + 3초) 그대로 두면 됩니다. 신 펌웨어에서는 3초 여유가 조금 남지만 문제 없습니다.
3. 예약(schedule)의 10초 분무도 동일하게 한 번에 나갑니다.

## 3. 반영 상태

| 구분 | 상태 |
|---|---|
| 서버 | 변경 없음. 9/23 배포된 분할·capabilities 수신 로직이 그대로 동작 |
| 펌웨어 | 빌드 완료(nano·supermini), 리플래시 대기. 같은 리플래시에 원격 재부팅·sys_state([APP_DEVICE_REBOOT_SYS_STATE_2026-09-28.md](APP_DEVICE_REBOOT_SYS_STATE_2026-09-28.md))·WiFi 절전 해제가 함께 들어감 |
| 확인 방법 | 리플래시된 기기의 `devices.capabilities.mist_max_ms == 30000` 이면 적용된 것. 10초 분무 후 `commands` 에 후속 행이 없으면 정상 |
